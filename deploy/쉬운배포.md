# susanfather.com — 셀러비온처럼 쉽게 올리기

카페24 서버/IP 몰라도 됩니다. **Render**(무료~저렴)에 올리고 도메인만 연결합니다.  
(셀러비온 = Vercel / 이 쇼핑몰 = Render — **하는 일은 거의 같음**)

---

## 왜 76.76.21.21 은 안 되나요? (한 줄)

그 IP는 **Vercel 전용**입니다.  
지금 쇼핑몰은 **회원·주문·DB**가 있어서 Vercel이 아니라 **Render**에 올립니다.  
DNS는 Render가 알려주는 주소로 넣으면 됩니다.

---

## 1단계 — GitHub에 코드 올리기

1. https://github.com 가입
2. **New repository** → 이름 예: `susanfather-shop`
3. PC에서 `이커머스 쇼핑몰` 폴더 내용을 그 저장소에 업로드  
   (GitHub Desktop 쓰면 드래그만 해도 됨)

---

## 2단계 — Render에 배포

1. https://render.com 가입 (GitHub로 로그인)
2. **New +** → **Web Service**
3. 방금 만든 GitHub 저장소 선택
4. 설정:

| 항목 | 값 |
|------|-----|
| Name | susanfather-shop |
| Runtime | Node |
| Build Command | `npm install && npm run seed` |
| Start Command | `npm start` |

5. **Environment** (환경 변수) 추가:

```
NODE_ENV=production
SITE_URL=https://susanfather.com
JWT_SECRET=아래명령으로_긴문자열_만들기
DB_PATH=/opt/render/project/src/server/data/shop.db
```

JWT 만들기 (PC 터미널):

```
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
```

6. **Create Web Service** → 5~10분 후  
   `https://susanfather-shop.onrender.com` 같은 주소가 생김 → 여기서 쇼핑몰 열림

---

## 3단계 — susanfather.com 연결 (카페24 DNS)

Render 대시보드 → 해당 서비스 → **Settings** → **Custom Domains**

- `susanfather.com` 추가
- `www.susanfather.com` 추가

Render가 **넣을 DNS 값**을 화면에 보여줍니다. (IP 또는 CNAME — Render 안내 그대로)

카페24 → 도메인 → **호스트 IP(A레코드) / CNAME** 관리:

- Render가 **A 레코드 + IP** 라고 하면 → A레코드에 그 IP
- Render가 **CNAME** 이라고 하면 → CNAME에 `xxxx.onrender.com`

**76.76.21.21 은 넣지 마세요** (Vercel용)

저장 후 30분~24시간 → **https://susanfather.com** 접속
