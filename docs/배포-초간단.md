# susanfather.com — 웹사이트만 올리기 (앱 아님)

## 이게 뭔가요?

- PC에 있는 **쇼핑몰 폴더** → 인터넷 주소 **https://susanfather.com** 에서 누구나 브라우저로 접속
- **앱 설치 없음**, **앱스토어 없음**
- 셀러비온(sellervion.shop)이랑 **똑같은 종류** (웹사이트)

---

## 왜 DB 이야기가 나오나요?

웹사이트만 만들어도 **회원·주문·리뷰**는 어딘가에 저장해야 합니다.  
셀러비온도 Vercel 안에 DB가 있습니다. (Neon 안 써도 됨)

**Neon은 선택** — 안 가입해도 됩니다.

---

## 가장 쉬운 방법 (셀러비온이랑 같은 Vercel)

### 1) GitHub에 코드 올리기

1. https://github.com/new → 저장소 이름 `susanfather-shop` → Create  
2. PC에서:

```powershell
cd "C:\Users\User\Desktop\이커머스 쇼핑몰"
npm run github:push
```

(로그인 창 나오면 GitHub 로그인)

---

### 2) Vercel에서 사이트 만들기

1. https://vercel.com 로그인 (셀러비온 할 때 쓴 계정이면 그대로)  
2. **Add New → Project** → `susanfather-shop` Import  
3. **Storage** 탭 → **Create Database → Postgres** (Vercel 안에서 DB 생성, Neon 불필요)  
4. 프로젝트에 DB 연결 → `DATABASE_URL` 자동 연결됨  
5. **Environment Variables** 추가:

| 이름 | 값 |
|------|-----|
| JWT_SECRET | 아무 긴 문자열 32자+ |
| NEXT_PUBLIC_SITE_URL | https://susanfather.com |

6. **Deploy** 클릭 → 몇 분 후 `xxx.vercel.app` 에서 쇼핑몰 열림

7. 터미널에서 (또는 Vercel → Settings → 한 번 실행):

```powershell
npx prisma db push
npm run db:seed
```

(Vercel 대시보드 **Storage** 또는 로컬에서 `.env`에 DATABASE_URL 복사 후 실행)

---

### 3) 도메인 연결 (카페24)

**네임서버는 그대로** 두고, **A레코드**만:

| 호스트 | 값 |
|--------|-----|
| @ | 76.76.21.21 |
| www | cname.vercel-dns.com |

Vercel → 프로젝트 → **Domains** → `susanfather.com` 입력
