# 결제 방법 안내 (토스페이먼츠 없이 운영)

## 1. 무통장 입금만 사용 (추천 · PG 가입비 없음)

이미 쇼핑몰에 **무통장 입금** 주문이 구현되어 있습니다.

### 관리자 설정

1. https://susanfather.com/admin 접속
2. **설정** → **결제 설정**
3. **「온라인 카드·간편결제 사용」 체크 해제**
4. 은행 / 계좌번호 / 예금주 입력 후 **저장**

### 주문 처리

1. 고객이 **무통장 입금** 선택 후 주문
2. 주문 상태: **입금 대기** (`awaiting_deposit`)
3. 통장 입금 확인 후 관리자 **주문 관리**에서 상태를 **입금완료·배송준비** 등으로 변경

토스페이먼츠 심사·가입비 **불필요**합니다.

---

## 2. 다른 PG(결제대행)도 비슷함

| 방식 | 특징 |
|------|------|
| 토스페이먼츠 | 심사, 가입비·연회비, 카드/간편결제 |
| KG이니시스, NHN KCP, 나이스페이 등 | 마찬가지로 계약·심사·수수료 |
| 네이버페이·카카오페이 직가맹 | 별도 심사, 쇼핑몰 연동 개발 필요 |

**소규모·초기**에는 무통장 입금이 가장 빠르고 비용이 적습니다.

---

## 3. 대안 (쇼핑몰 밖)

- **네이버 스마트스토어 / 쿠팡 로켓그로스** — 플랫폼이 결제 처리 (수수료 있음)
- **카카오톡 채널·인스타 DM 주문** — 수동 정산 (자동 주문·재고 연동 없음)
- **카카오뱅크·토스 송금 링크** — 안내 문구만 넣고, 입금 확인은 수동

---

## 4. 나중에 카드 결제를 쓰고 싶을 때

1. 토스페이먼츠(또는 다른 PG) 계약·키 발급
2. Vercel 환경변수 `TOSS_CLIENT_KEY`, `TOSS_SECRET_KEY` 설정
3. 관리자 **결제 설정**에서 **온라인 카드·간편결제 사용** 체크
