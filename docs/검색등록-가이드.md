# 수산아빠 — 검색엔진 등록 가이드

사이트 주소: **https://susanfather.com**

코드에 이미 적용된 항목:

- `robots.txt` — 검색 로봇 안내
- `sitemap.xml` — 홈 + 상품(`/p/상품ID`) + 이용약관 등 URL 목록
- 메타 태그·Open Graph·상품 구조화 데이터(JSON-LD)
- 상품별 주소 예: `https://susanfather.com/p/fr1`

---

## 1. Google 검색 (Search Console)

1. [Google Search Console](https://search.google.com/search-console) 접속
2. **속성 추가** → URL 접두어: `https://susanfather.com`
3. 소유권 확인 (아래 중 하나)
   - **HTML 태그**: `public/index.html`에 `google-site-verification` 메타 태그 적용됨
   - **DNS TXT**: 도메인 업체에 `google-site-verification=y1b8X8MZSLf5jFQ8TTRM_MyvuPV8gGHia-x9qeqi1kQ` 추가
4. **Sitemaps** 메뉴 → 새 사이트맵 제출: `sitemap.xml`
5. **URL 검사**에서 `https://susanfather.com/` 색인 요청

색인까지 보통 **며칠~2주** 걸릴 수 있습니다.

---

## 2. 네이버 검색 (서치어드바이저)

1. [네이버 서치어드바이저](https://searchadvisor.naver.com/) 접속
2. 사이트 등록: `https://susanfather.com`
3. 소유권 확인 (아래 중 하나)
   - **HTML 파일**: `https://susanfather.com/navercd43f69b8731fed6057410ad6ce34b4d.html`
   - **HTML 태그**: `public/index.html`에 `naver-site-verification` 메타 태그 적용됨
4. **요청 → 사이트맵 제출**: `https://susanfather.com/sitemap.xml`
5. **웹페이지 수집 요청**으로 메인·상품 URL 제출

---

## 3. Bing (선택)

1. [Bing Webmaster Tools](https://www.bing.com/webmasters)
2. 사이트 추가 후 `sitemap.xml` 제출

---

## 4. 운영 시 참고

- 상품을 추가·수정한 뒤 배포하면 `publish` 시 **sitemap.xml이 자동 갱신**됩니다.
- 장바구니·결제·마이페이지는 검색에 노출되지 않도록 `noindex` 처리되어 있습니다.
- 검색 순위는 콘텐츠·리뷰·외부 링크 등에 따라 달라지며, 등록만으로 1페이지 보장은 없습니다.

---

## 5. Google 소유권 확인용 메타 태그 (필요 시)

Search Console에서 HTML 태그 방식을 선택하면 예시:

```html
<meta name="google-site-verification" content="여기에_발급코드" />
```

`public/index.html`의 `<head>` 안에 한 줄 추가 후 다시 배포하세요.
